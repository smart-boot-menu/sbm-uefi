# IA32 (i686 UEFI)

`i686-unknown-uefi` is a Tier 2 Rust target. SBM 0.1 does not ship an IA32 binary.

Shared discovery, policy, and drawing code uses `u32` geometry and `CpuArch::Ia32` in the loader-name and PE-machine tables (`0x14C`, `bootia32.efi`, `grubia32.efi`). Nothing in those crates assumes a 64-bit pointer.

IA32 is deferred because:

- The first milestone is x86-64 and AArch64, which cover the lab machines and Apple Silicon U-Boot.
- OVMF IA32 is a separate firmware image and a third QEMU job.
- 32-bit UEFI tablets need a measured binary-size pass of their own. The AArch64 and x86-64 size numbers must not be copied across.

A later milestone can add `cargo check --target i686-unknown-uefi` once an IA32 machine or `sbm-lab` fixture exists.
